# Abhijeet Minz - Portfolio

Personal portfolio website built with HTML, CSS, and hosted on GitHub Pages.

## Features

- Responsive design (works on desktop, tablet, mobile)
- Portfolio showcasing projects
- About section
- Contact links
- Clean, modern styling

## Live Website

Visit: https://Abhijeet-Minz.github.io

## How to Update

1. Edit `index.html` to update content
2. Edit `style.css` to change styling
3. Commit and push changes to GitHub
4. Website updates automatically

## Customization

- Update the projects section with your own projects
- Modify colors in `style.css` `:root` variables
- Add more sections as needed
- Update social links in the contact section
